# YTMD Better Lyrics (Community Fork) v2.0.13

This is an unofficial community build maintained by Strax1357. It is based on [YouTube Music Desktop App](https://github.com/ytmdesktop/ytmdesktop) and includes [Better Lyrics](https://github.com/better-lyrics/better-lyrics). It is independent of and is not endorsed by either upstream project or Google.

## Included

- YouTube Music Desktop App with Better Lyrics' time-synced lyrics and translation support.
- Desktop translation settings, including language rules based on original lyrics.
